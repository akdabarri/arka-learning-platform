## 📖 Mengenal A.R.K.A.

**A.R.K.A. (Adaptive Reasoning & Knowledge Architecture)** adalah media pembelajaran komputasional berbasis web (*educational game-based learning*) yang dirancang khusus untuk memfasilitasi penalaran logis, dekomposisi langkah, dan penalaran spasial bagi siswa jenjang Sekolah Dasar (Kelas 1–6 SD / Fase A, B, dan C).

Berlatar belakang di kepulauan kosmik fiktif bernama **Pulau Solaria**, siswa memandu robot Arka melintasi labirin kisi dengan menyusun balok perintah logika algoritma guna mengumpulkan Kristal Surya, menanam mangrove ekologis, dan mengaktifkan pompa air pembangkit energi surya.

> [!NOTE]  
> **Keamanan Afektif Siswa**: Platform ini dirancang secara sengaja **tanpa papan peringkat publik (*leaderboard-free*)** untuk mencegah kecemasan kinerja (*academic anxiety*), meminimalisir rivalitas destruktif, dan menumbuhkan motivasi intrinsik melalui pendekatan eksperimentasi yang aman dari rasa takut salah.
